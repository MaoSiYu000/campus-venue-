# 图片显示破损、点击跳转主页 - 修复说明

## 问题现象

1. **管理员上传的场地图片**：学生端显示为破损图标
2. **点击图片**：新标签页打开的是系统主页，而不是图片本身

## 原因分析

- 图片路径为 `/uploads/venues/xxx.jpg`，由**后端**提供（NestJS 静态资源）
- 当前 Nginx 只代理了 `/api/` 到后端，**未代理 `/uploads/`**
- 请求 `/uploads/venues/xxx.jpg` 时，Nginx 在网站根目录（前端 dist）中查找，找不到文件
- SPA 配置 `try_files ... /index.html` 导致返回 `index.html`，浏览器显示主页 → 表现为“点击图片打开主页”
- 图片 `<img src="/uploads/...">` 加载到的是 HTML 而非图片 → 表现为“破损图片”

## 修复步骤

在服务器 `120.26.124.180` 上修改 Nginx 配置，**增加 `/uploads/` 的代理**。

### 1. 找到站点配置文件

常见路径示例：
- 宝塔：`/www/server/panel/vhost/nginx/` 下对应站点
- 手动配置：`/etc/nginx/sites-available/` 或 `nginx.conf` 中的 `server` 块

### 2. 在 `server` 块内添加（放在 `location /` 之前）

```nginx
location /uploads/ {
    proxy_pass http://127.0.0.1:3000;
    proxy_set_header Host $host;
    proxy_set_header X-Real-IP $remote_addr;
    proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
    proxy_set_header X-Forwarded-Proto $scheme;
}
```

### 3. 重载 Nginx

```bash
nginx -t && nginx -s reload
```

### 4. 验证

- 访问：`http://120.26.124.180/uploads/venues/` 下任意已上传图片
- 应能直接看到图片，且点击图片在新标签页中正确显示
