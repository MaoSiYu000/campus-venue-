# 前端静态图片规范存放位置

本目录为前端静态图片的规范位置。

## 登录页轮播背景

请将登录页轮播背景图命名为 **1.png**、**2.png**、**3.png**、**4.png** 放在本目录下。

- **建议尺寸**：1920×1080 或更大，比例 16:9。
- **格式**：JPG、WebP、PNG 均可。

未放置图片时，登录页使用默认渐变背景。

## 页面底纹（各角色首屏标题区）

系统管理员「预约总览」、学生/老师「场地列表」、场地管理员「审核申请」等页面的首屏标题区（约占页面高度 1/4）底部会使用一张底纹图。

请将页面底纹图命名为 **页面底纹.png** 放在本目录下（即 `frontend/public/images/页面底纹.png`）。系统管理员预约总览、学生/老师场地列表、场地管理员审核申请等页面的标题区会使用该图片（拉伸填充）。未放置时显示默认渐变背景。
