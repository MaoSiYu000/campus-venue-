# 校园场地预约系统 - 功能测试步骤

请保证：**后端**（`npm run start:dev`）和**前端**（`npm run dev`）都已启动，浏览器打开 **http://localhost:5173**。

---

## 一、学生/老师端测试

### 1. 登录
- 身份选 **「学生/老师」**
- 学号：**2024001**
- 密码：**123456**
- 点击 **登录**

### 2. 首次登录改密（若提示）
- 若提示「首次登录请修改密码」，在改密页：
  - 原密码：**123456**
  - 新密码：自设（至少 6 位），再填一次确认
  - 点击 **确认修改**
- 改完后会退出，用**新密码**重新登录

### 3. 公告
- 登录后先进入「通知与公告」
- 若有公告，阅读后点击 **「确认并进入主界面」**
- 进入主界面（场地列表）

### 4. 场地列表与筛选
- 菜单点 **「场地列表」**
- 试试筛选：类型选「报告厅」、容量范围、勾选「投影」「音响」、可用选「可用」
- 点击 **查询**，看列表是否变化
- 点击某一**场地卡片**，进入详情

### 5. 场地详情与预约入口
- 在详情页查看：类型、容量、位置、地址、开放时间、设备
- 点击 **「预约此场地」**，应跳到预约申请页

### 6. 提交预约申请
- 菜单点 **「预约申请」**（或从详情页点「预约此场地」）
- 选择 **场地**（下拉选一个）
- **使用日期**：选一个未来日期
- **开始时间** / **结束时间**：各选一个（如 09:00、11:00）
- 看「时段状态」：应显示「该时段可预约」或「该时段已被预约或不可用」
- 填写：活动名称、主办单位、预计人数、负责人、联系电话、活动说明（可选）
- 策划书（可选）：点「选择文件」选一个 PDF/Word
- 点击 **提交申请**
- 成功后会跳转到「我的预约」

### 7. 我的预约
- 菜单点 **「我的预约」**
- 查看刚提交的申请，状态应为 **「待审核」**
- 点 **详情** 看完整信息
- 对「待审核」或「已通过」且未开始的可点 **取消**，确认后状态变为「已取消」

### 8. 退出
- 右上角点 **「退出」**，应回到登录页

## 二、场地管理员端测试

### 1. 登录
- 身份选 **「场地管理员」**
- 工号：**va001**
- 密码：**123456**
- 点击 **登录**

### 2. 公告
- 若有必读公告，阅读后点击 **「确认并进入主界面」**

### 3. 待处理申请
- 菜单点 **「待审核」**
- 应能看到学生端刚提交的「待审核」申请（若该场地在 va001 管辖范围内）
- 点 **详情** 查看活动信息、策划书链接
- 点 **通过**：确认后状态变为已通过，学生会收到通知
- 或点 **驳回**：在弹窗中**必填驳回理由**，确认后学生收到驳回通知

### 4. 审批记录
- 菜单点 **「审批记录」**
- 查看历史审批（待审核/已通过/已驳回等）

### 5. 场地管理
- 菜单点 **「场地管理」**
- 列表为当前管理员管辖的场地
- 点 **编辑**：可改名称、地址、可用状态（开关）
- 点 **不可用时段**：选开始/结束时间、原因，点「添加」后该时段不可被预约，已预约用户会收到通知

### 6. 预约总览
- 菜单点 **「预约总览」**
- 查看管辖范围内场地的预约占用情况（待审核、已通过）

### 7. 退出
- 右上角点 **「退出」**

## 三、系统管理员端测试

### 1. 登录
- 身份选 **「系统管理员」**
- 用户名：**admin**
- 密码：**123456**（若执行过 `npm run seed` 则用 **admin123**）
- 点击 **登录**

### 2. 预约总览
- 菜单点 **「预约总览」**
- 查看全校所有预约记录

### 3. 场地管理
- 菜单点 **「场地管理」**
- 可看到**全部**场地
- 点 **编辑**：修改名称、地址、可用状态（设为不可用时已预约用户会收到通知）

### 4. 账号管理
- 菜单点 **「账号管理」**
- **学生/老师** 标签：查看用户列表，对某用户点 **发送通知**，填标题和内容后发送
- **场地管理员** 标签：查看管理员列表及管辖场地
  - **发送通知**：给指定场地管理员发站内通知
  - **管辖范围**：勾选/取消勾选场地，保存后该管理员的管辖范围更新

### 5. 发布公告
- 菜单点 **「发布公告」**
- 填写标题、内容，勾选「登录必读」则学生/场地管理员下次登录需先看公告
- 点击 **发布**
- 下方可看历史公告列表

### 6. 退出
- 右上角点 **「退出」**
