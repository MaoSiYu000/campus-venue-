# 账号批量导入说明

系统管理员在「账号管理」页可点击 **下载 Excel 模板** 获取标准格式，按格式填写后使用 **批量导入** 上传。

## Excel 格式要求

- **工作表「学生」**（或「用户」）
  - 第一行为表头，必须包含列：**学号**
  - 建议列：**姓名**、**初始密码**（不填则默认 123456）
  - 从第二行起每行一条学生/老师账号

- **工作表「场地管理员」**
  - 第一行为表头，必须包含列：**工号**
  - 建议列：**姓名**、**初始密码**（不填则默认 123456）
  - 从第二行起每行一条场地管理员账号

同一 Excel 可同时包含「学生」和「场地管理员」两个工作表，导入时会分别处理；未包含的工作表会被跳过。
